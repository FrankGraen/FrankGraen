## Selected Projects
### EgoPush
**Egocentric Multi-Object Rearrangement for Mobile Robots via Constrained Teacher Observability**

参与仅依靠第一视角视觉的移动机器人长程多物体非抓取式重排研究。项目结合对象中心表示、受限教师观测与策略蒸馏，在部署时无需全局地图、全局定位或外部追踪，并实现向 TurtleBot 的零样本迁移。

[项目网站](https://ai4ce.github.io/EgoPush/) · [论文 / arXiv](https://arxiv.org/abs/2602.18071)

### Humanoid Badminton
**Learning Dynamic Racket Skills from Limited Human Motion Data · CoRL 2026**

参与人形机器人羽毛球技能学习研究。项目通过动作数据增强、层级强化学习与条件对抗正则，将有限的人类动作数据转化为多样化击球技能，实现包含正手、反手及高动态跳跃回球的人机连续对打。

[项目网站](https://sunlight02.github.io/humanoid-badminton/) · [论文 / arXiv](https://arxiv.org/abs/2609.31840)
